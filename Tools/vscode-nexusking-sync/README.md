# NexusKing Mobile IDE Sync — VS Code Extension

Đồng bộ code **2 chiều theo thời gian thực** giữa VS Code trên máy tính và ứng dụng **NexusKing Mobile IDE** trên iPhone / iPad qua cả **4G/5G (`wss://build.kaydus.xyz/v1/sync`)** lẫn **Wi-Fi LAN (`ws://<LAN>:30120`)** với mã hóa đầu cuối **AES-256-GCM**.

## Cài đặt nhanh
1. Tải `nexusking-vscode-sync.vsix` từ trang **GitHub Releases** của `NexusKing`.
2. Mở VS Code, nhấn `Ctrl+Shift+X` (macOS `Cmd+Shift+X`) mở **Extensions**.
3. Bấm nút `⋯` (Views and More Actions) -> **Install from VSIX...** -> chọn `nexusking-vscode-sync.vsix`.
4. Bấm vào biểu tượng **`NexusKing Sync`** ở góc dưới bên phải thanh trạng thái VS Code để lấy **Mã PIN 6 số** (chỉ cần nhập 1 lần, máy tự nhớ Khóa Vĩnh Viễn cho các lần sau).
